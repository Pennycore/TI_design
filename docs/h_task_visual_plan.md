# H 题视觉组计划

## 视觉目标

题目要求检测摆杆凹槽内直径约 1 cm 的钢球位置，因此视觉任务从“识别赛道钢球”改为“测量钢球在 25 cm 摆杆上的一维坐标”。

建议 K230 摄像头固定在摆杆凹槽上方，画面覆盖整根摆杆。视觉输出：

- `position_mm`：钢球相对中心点 O 的位置，左负右正，范围约 `-125` 到 `+125` mm。
- `velocity_mm_s`：一维速度估计，左负右正。
- `raw_x`：画面横坐标，便于现场检查标定。
- `confidence`：0 到 100。
- `flags`：bit0 detected，bit1 stable，bit2 on_target，bit3 predicted。

## 推荐脚本

K230 端优先使用：

`k230/rod_ball_blob_canmv.py`

先在 CanMV IDE 里看串行终端输出：

```text
BLOB frame=120 fps=50.8 x=315 pos=0mm v=2mm/s ...
```

如果 `pos` 随钢球移动方向正确，并且静止时波动小于约 `±5 mm`，再接入 TI 板闭环。

## 标定步骤

1. 摄像头固定在摆杆上方，至少完整覆盖题目要求的中心 `-50 mm` 到 `+50 mm` 区域。
2. 在脚本中调 `ROD_CENTER_Y`，让黄色横线压在凹槽中心。
3. 当前三点标定是 `x=195 -> -50 mm`、`x=315 -> 0 mm`、`x=442 -> +50 mm`。
4. 钢球依次放到三处刻度，确认串口打印接近 `-50`、`0`、`+50 mm`。
5. 摄像头位置一旦改变，必须重新测这三个 x 值。

## 今天优先级

1. 机械组先做摆杆和平滑凹槽，凹槽内壁不能有增摩材料。
2. 视觉组先完成静态测量：O、+5 cm、-5 cm 三点误差小于 1 cm。
3. 车控组继续把循迹一圈和 A 点停车跑稳。
4. 系统联调时，先让 TI 只接收视觉位置，不立刻控制摆杆。
