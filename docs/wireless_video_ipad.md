# K230 无线图传与 iPad 监视

## 推荐结构

第一阶段直接使用庐山派板载 Wi-Fi 创建热点：

```text
K230 摄像头 -> H.264 编码 -> K230 2.4G Wi-Fi 热点
                                      |
                                      v
                           iPad Wi-Fi + VLC + 系统录屏
```

这套链路不需要互联网。K230 和 iPad 都应置于赛道规定的位置：K230 固定在车上，iPad 位于环形线路外。

## K230 测试程序

在 CanMV IDE 中打开并运行：

```text
k230/wifi_rtsp_test_canmv.py
```

默认参数：

- 热点名称：`H_BALL_CAR`
- 热点密码：`hball2026`
- 视频：H.264，640x480
- RTSP 端口：`8554`
- 会话名称：`ball`

程序启动后，串行终端会打印实际 RTSP 地址，例如：

```text
RTSP stream ready: rtsp://192.168.4.1:8554/ball
```

必须使用终端实际打印的地址，不要固定照抄示例 IP。

## iPad 操作

1. 在 iPad 安装 VLC。
2. 打开“设置 -> Wi-Fi”，连接 `H_BALL_CAR`，密码为 `hball2026`。
3. iPad 提示该网络无法访问互联网时，选择继续使用此 Wi-Fi。
4. 打开 VLC 的网络串流功能，输入 K230 终端打印的 RTSP 地址。
5. 关闭自动锁屏，打开勿扰模式，并给 iPad 接上电源。
6. 每次测试前启动 iPad 系统录屏，测试结束后停止录屏。
7. 立即在“照片”中回放一次，确认整段视频存在且没有中断。

## 比赛前验收

- 连续推流至少 10 分钟，不黑屏、不自动退出。
- 人拿着小车绕完整赛道行走，确认最远位置仍有画面。
- 连续完成三次“开始录屏 -> 测试 -> 停止 -> 回放”。
- 视频中始终能看清球、凹槽和球的运动方向。
- iPad 剩余存储空间大于 5GB，关闭通知、自动锁屏和系统更新。
- K230 供电稳定，Wi-Fi 天线区域不要被电池、金属板或电机遮挡。

## 现场增强方案

比赛环境中 2.4G 干扰可能较强。更稳妥的布置是在赛道外放一个独立小路由器，固定为 2.4G、20MHz 带宽和固定信道，K230 与 iPad 都连接该路由器。该方案需要把 K230 网络模式由 AP 改为 STA，确认路由器型号后再配置。

若裁判明确要求可见的独立接收模块，而不认可 iPad 内置 Wi-Fi 作为接收端，应改用无线 HDMI 发射器和接收器，接收器连接带录像功能的电脑或采集设备。
